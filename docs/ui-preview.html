TableTalk

A conversation,
across languages.

English ↔ Español · on one phone

Place the phone between you. Each person has captions and a speaking button facing their side of the table.

Tap either speaking button to show a sample turn. Rotate the view to read the Spanish side from the other seat.

Sample layout only. This preview uses fixed example sentences. It never accesses a microphone, loads a model, or translates speech. The Android starter implements the local speech pipeline separately.

The native app imports a small speech model and prepares Spanish translation before the visit. The visit APK removes internet permission. Build and device-testing instructions are in README.md.
